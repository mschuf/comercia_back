# Q: que significa programacion pausada y como reanudar

## Answer

Expanded from original query via vocab: [tarea, tareas, programacion, frecuencia, ocurrencia, visitas]. La programacion pausada corresponde a programacion.activo=false; no se calculan nuevas ocurrencias de visita. Se reanuda desde Visitas > Programacion: abrir Editar del local, marcar Programacion activa y Guardar. El acceso para guardar exige supervisor de agenda y mantiene intacto el historial y tareas ya realizadas.
